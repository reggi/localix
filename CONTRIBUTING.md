# Contributing

Use Conventional Commits for every commit.

```text
<type>(optional scope): <description>
```

Common types are `feat`, `fix`, `docs`, `refactor`, `test`, `build`, `ci`, and `chore`. Breaking changes use `!` before the colon or a `BREAKING CHANGE:` footer.

Release Please uses these commits to prepare release pull requests, update `CHANGELOG.md`, create semantic version tags, and publish GitHub Releases.
